    Import local records

    GenBank, FASTA, CSV, or XLSX · multiple files supported. Files stay on this computer.

    Source labels record provenance; they do not fetch remote data.
    Catalogue format and limits

    CSV and XLSX use a header row with name (or id) and an optional sequence column. Without an inline sequence, each row must match exactly one uploaded or existing record by name or ID. Optional topology values: circular, linear, unknown. Other columns are retained as catalogue metadata.

    Use values-only spreadsheets. Maximum 1,000 records per import and 100,000 bases per record. Ambiguous matches and conflicting topology require correction; duplicate sources are reported.
